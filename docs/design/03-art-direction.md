## 1.1 개정 예정 (2026-10-11)

- **A1 재검토:** 첫 섬 결과가 "도형으로만 보임" → 스타일은 **두 데모(Desert Light·Abandoned Spaceship)의 표현 방식**을 참고해 다시 정한다: 조각된 부드러운 형태, 실사 텍스처 블렌딩 지형, 빛·안개·AO.
- **분위기·회복 후 색감 참고:** 사용자 제공 컨셉 이미지 2장 (광활한 초원, 화면을 채우는 뭉게구름 하늘, 원경의 겹겹 산, 청명한 파랑·초록). 그래픽 자체를 따라 하지 않는다. 거대한 구조물 요소는 쓰지 않는다.
- **렌더러 확정 (2026-10-11):** Forward+ — 태블릿 평균 48~78 FPS. 이 문서의 7장 성능 예산과 스타일은 Forward+ 기준으로 개정한다.

## 2. 원칙: "색이 이야기를 한다"

- 텍스처를 거의 쓰지 않는다. 면마다 단색 + 높이·방향 그라데이션으로 칠한다.
- 형태는 단순하게, **실루엣이 먼저 읽히게** (기둥 3 — 실루엣이 플레이어를 부른다).
- 빛은 언제나 생명의 표현이다. 착취는 잿빛·어둠으로, 회복은 빛·색으로 표현한다.

## 3. 팔레트

| 대상 | 잿빛 (회복 전) | 회복 후 |
|---|---|---|
| 풀·언덕 | 푸른 회색 `#8A9298` | 연두~초록 `#9CC46A` → `#5E9C4A` |
| 바위·절벽 | 차가운 회색 `#7C8088` | 따뜻한 황토·적갈색 `#C49A6C` / `#9A6B4F` |
| 물 | 탁한 청회색 `#6E7C86`, 반사 약함 | 맑은 청록 `#3FA7B5`, 반짝임 |
| 하늘 | 납빛 `#9AA0A6`, 탑 위 어두운 구름판 | 하늘색 `#7EC3EA`, 뭉게구름 |
| 마을 | 바랜 나무색 `#9C9488` | 주황 지붕 `#D9784A`, 흰 벽 `#F2EDE3` |

**회색 처리 제외 — 항상 고채도 (읽어야 하는 정보):**
- 생명력의 빛: 초록 `#7CF29A` · 금 `#F2D27C`
- 적 예고 신호: 🟡 `#FFD933` / 🔴 `#FF2619`
- 기계 약점 코어: 청록 `#4DE6FF`
- 상호작용 대상의 하이라이트

수치는 첫 구현 후 태블릿 화면에서 보정한다.

## 4. 회색 → 컬러 구현

- 지형·소품이 **공용 spatial 셰이더 하나**를 쓴다. 정점 색 또는 재질 파라미터로 "회복 후 색"을 받고, 셰이더가 같은 색의 잿빛 판(채도 15% + 약간 푸른 기)을 함께 계산한다.
- 전역 셰이더 변수 `vitality_center`, `vitality_radius`로 두 판을 섞는다. 경계는 약 10m 폭으로 부드럽게.
- 고채도 예외(3장)는 셰이더의 `keep_color` 플래그나 별도 발광 재질로 처리한다.

## 5. 빛과 대기

- 해(DirectionalLight) 1개 + 하늘색 환경광. 그림자 거리는 짧게 (태블릿).
- **거리 안개 + 높이 안개**로 탑·산 실루엣을 겹겹이 보이게 한다. 회화풍 원근감의 핵심.
- Glow는 생명력 빛과 코어에만 약하게.
- 탑 주변: 잿빛 줄기가 빨려 드는 소용돌이(입자) + 탑 위 어두운 구름판. 정지 시 초록·금빛 입자가 터져 땅으로 흐른다.

## 6. 디자인 언어

- **고대 장치 (기계·탑·수문):** 각진 금속 판 + 청록 발광 코어 + 예고 신호용 눈. 탑과 기계는 같은 문명의 같은 언어로.
- **사람·마을:** 둥글고 따뜻한 나무·천. 고대의 각진 금속과 대비.
- **주인공:** 마을 사람과 같은 계열의 옷 + 포인트 색 1개 (예: 망토).

## 7. 성능 예산 (Galaxy Tab S11 Ultra, 60 FPS 목표 / 30 하한)

| 항목 | 예산 |
|---|---|
| 화면당 삼각형 | 약 30만 이하 |
| 그림자 드리우는 빛 | 1개 |
| 입자 | 2,000개 이하 |
| 재질 | 공용 셰이더 1 + 물 + 하늘 + 발광 (최소화) |
| 3D 해상도 스케일 | 0.75부터 (실측 조정) |

## 8. 참고 (처음 분석한 Godot 데모)

- **Desert Light:** 안개와 빛에 의한 원근감, 큰 하늘 → 섬 전경·원경.
- **Abandoned Spaceship:** 어두운 구조물 안의 발광 디테일 → 탑 내부·기계 코어.
