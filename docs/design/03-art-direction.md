## 1. 결정 로그
| # | 질문 | 결정 |
|---|---|---|
| A1 | 전체 스타일 | **큰 실루엣 · 단순한 색면 · 저채도 팔레트 · 대기 원근 · 절제된 조명** (Omno의 원리를 참고, 에셋·디자인은 복제하지 않음) |
| A2 | 회복 전/후 | 고갈 = 창백한 청회색 저채도, 회복 = 맑은 파랑·자연스러운 초록(형광 금지). 회복은 색 + 식생 밀도 + 빛 + 생명 입자가 함께 변함 |
| A3 | 에셋 | **코드 생성**(시드 기반 바위·나무·풀·건축 부품·구름) — 사진 텍스처·노멀맵 없음. v0.2 실사 에셋은 첫 섬 교체 후 삭제 |
| A4 | 렌더러 | **Compatibility** (웹 내보내기 가능). 틈새 그늘 = 정점색 AO |

| A6 | 광활함 | 하늘 그라데이션(천정 진하게·지평선 밝게) + 원경 능선 2겹 + 안개로 하늘에 녹임 |

## 2. 원칙
1. **빛은 생명의 표현.** 고갈 = 잿빛·흐림, 회복 = 빛·색·바람·생명 입자.
2. **실루엣 먼저, 디테일은 가까이서만.** 멀리서도 절벽·나무·폐허·탑이 구별되어야 한다.
3. **색면 우선.** 형태는 면의 명암으로, 낡음은 명도 얼룩·파손 형태로. 반복될 무늬 자체를 만들지 않는다.
4. **강조색은 중요한 것에만**: 생명 에너지 `#76C9C3`, 적 예고 `#FFD933`/`#FF2619`, 코어 `#4DE6FF` (회복값과 무관하게 고채도).
5. **주광원이 형태를 만든다.** 환경광은 약하게(해 대비 약 0.45), Filmic white 6 (중간톤 들뜸 방지 — 실측).

## 3. 팔레트
`scripts/core/style_palette.gd`가 단일 출처 (설계서 5장 시작값, 테스트 씬 조정 반영).

## 4. 구현 요약
| 요소 | 방식 |
|---|---|
| 공통 재질 | `style_lit` — 기본색(고갈↔회복) × 정점색 명도 × 수십 m 주기 얼룩, AO = 정점색 A |
| 지형 | `style_terrain` — 풀/흙/절벽 바위/모래 색 띠(경사·높이·노이즈), 평면 음영(먼 곳은 부드럽게) |
| 식생 | `style_foliage` — 덩어리형 풀 3종·나무 3종, 정점 바람, 인스턴스 문턱값으로 회복 밀도, 거리 페이드 |
| 하늘 | `style_sky` — 천정↔지평선 그라데이션, 지평선 = 안개색 |
| 물 | `style_water` — 단색 + 얕음/깊음(미리 계산한 깊이) + 약한 파문, 깊이 텍스처 안 읽음 |
| 회복 | `Recovery`(모델) → `RecoveryMap`(128² 텍스처, 보간) → 전역 `recovery_map`·`recovery_here` |
| 검증 | `scenes/style_test.tscn` + `tools/shots.sh <tag> r0,r50,r100 style_test` |

## 5. 성능 예산
그리기 호출 < 150, 삼각형 < 30만, 그림자 1개(60m, 2분할). 태블릿·웹 60 FPS 목표 / 45 하한. 효과 추가 시 `docs/perf/`에 재측정.

- D 통합: 옛 실사 그래픽 삭제, 회복 지도 연결(탑 = 1.0), 웹 내보내기(`markers.json` 내보내기 필터 포함)·태블릿 Chrome 확인.
