# 그래픽 설계서 (Art Direction) — v0.2

> 상태: 개정 (2026-10-11) · 상위 문서: `01-core-design.md` (기둥 3 "고요한 발견", 10장 렌더링 = Forward+)
> v0.1(회화풍 로우폴리)은 첫 섬 결과 "도형으로만 보임" → 폐기. 이 판은 **두 데모의 표현 방식**을 기준으로 다시 쓴다.

## 1. 결정 로그

| # | 질문 | 결정 |
|---|---|---|
| A1 | 전체 스타일 | **밝은 사실풍** — 실사 텍스처 + 부드러운 형태 + 빛·안개·AO로 깊이. 채도는 실사보다 약간 높게(청명한 파랑·초록). 그래픽 표현은 **Desert Light · Abandoned Spaceship 두 데모**를 따른다 *(v0.1 회화풍 로우폴리 폐기)* |

| A5 | 분위기·색감 참고 | 사용자 컨셉 이미지 2장 — **광활함**(화면 2/3를 채우는 뭉게구름 하늘, 끝없는 초원, 원경의 겹겹 산, 공기 원근)과 **회복 후 색감**(청명한 파랑, 선명한 초록, 흰 구름). 그래픽 자체·거대 구조물은 따라 하지 않는다 |

## 2. 두 데모에서 가져오는 것 (분석 요약)

화면이 "도형"이 아니라 "장소"로 보이려면 **형태 · 표면 · 빛** 세 층이 모두 채워져야 한다. 첫 섬은 세 층이 모두 비어 있었다.

| 층 | Desert Light | Abandoned Spaceship | 우리가 쓰는 방법 |
|---|---|---|---|
| **형태** | 조각한 곡면 메시(바위·모래 바닥), 부드러운 음영 | 모듈 메시 + 트림 시트 | 지형 = **부드러운 법선**(평면 음영 폐기) + 고해상도 높이 지도. 실루엣 = **CC0 바위 모델**을 지형 위에 흩뿌림. 상자 건물은 텍스처 재질 + 모서리 경사 |
| **표면** | 단색 재질 + 돌 노멀맵 (빛이 일을 함) | 실사 텍스처 3장을 **정점 색·높이로 섞는 지형 셰이더**, 시차, ORM | **지형 셰이더**: 풀·흙·바위 텍스처를 경사·높이·노이즈로 섞음, 바위는 삼면 투영(늘어짐 방지), 높이 기반 경계(풀 사이로 흙이 비침) |
| **빛** | VoxelGI + SSAO + SSIL + 볼류메트릭 안개 + 하루 주기 | 라이트맵 + 반사 프로브 + SSAO·SSIL + 볼류메트릭 안개 + TAA | 해 1개 + **HDRI 하늘 환경광** + **SSAO·SSIL** + 약한 **볼류메트릭 안개** + 글로우. GI(VoxelGI/SDFGI)는 실측 전 보류 |
| **식물** | 거의 없음 | 알파 컷아웃 잎 판 + 역광 | **풀 덩어리**를 카메라 주변에만 대량 배치(MultiMesh), 바람은 정점 셰이더, 역광(backlight) |

## 3. 원칙

1. **빛은 언제나 생명의 표현.** 착취 = 잿빛·흐림, 회복 = 빛·색·바람. (탑 소용돌이·생명력 터짐 규칙 유지)
2. **광활함은 하늘과 거리에서.** 하늘이 화면의 절반 이상을 차지하는 구도를 기본으로, 원경은 공기 원근으로 하늘색에 녹인다.
3. **크기 단서를 지운다는 것은 없다.** 풀잎·자갈·바위가 있어야 눈이 거리를 잰다 — 넓은 땅일수록 근경 디테일이 필요.
4. **읽어야 하는 정보는 항상 고채도** (아래 4장 예외 목록).

## 4. 팔레트 (회복 후 = 컨셉 이미지 색감, 실측 후 보정)

| 대상 | 잿빛 (회복 전) | 회복 후 |
|---|---|---|
| 하늘 | 흐린 납빛, 낮은 구름층, 탑 위 어두운 구름 | **청명한 파랑 `#3E7FC4`→지평선 `#BFD6EA`, 흰 뭉게구름** |
| 풀·초원 | 바랜 회녹색 | **선명한 연두~초록 `#8CC63F` / `#4E8F2A`**, 끝에 흰 꽃 점 |
| 바위·절벽 | 차가운 회색 | 따뜻한 회갈색·이끼 |
| 물 | 탁한 청회색, 반사 약함 | 하늘을 비추는 청록, 반짝임 |
| 원경 산 | 안개에 묻힌 회색 실루엣 | 푸른 공기 원근 속 겹겹의 능선 |
| 마을 | 바랜 나무·회벽 | 주황 지붕·흰 벽 |

**회색 처리 제외 — 항상 고채도:** 생명력 빛(초록 `#7CF29A`·금 `#F2D27C`), 적 예고 🟡 `#FFD933` / 🔴 `#FF2619`, 기계 코어 청록 `#4DE6FF`, 상호작용 하이라이트.

## 5. 회색 → 컬러 구현 (v0.1 장치 유지, 텍스처 대응)

- 공용 셰이더 방식 유지: 전역 `vitality_center`·`vitality_radius`로 잿빛 판과 원래 색을 섞는다. 텍스처를 샘플한 **뒤** 채도를 낮추므로 지형·바위·건물 재질 모두 같은 장치로 바뀐다.
- **하늘:** 흐린 HDRI ↔ 맑은 HDRI 두 장을 하늘 셰이더에서 섞는다(회복 비율 = 탑 정지 연출과 동기).
- **풀:** 회복 전에는 짧고 누런 회색 풀(바람 약함), 회복 후 키·색·바람 세기가 커진다 — 같은 MultiMesh, 셰이더 값만 변경.
- **안개:** 회복 전 회색·짙게 → 회복 후 하늘색·옅게 (공기 원근은 유지).

## 6. 지형·사물 제작 규칙

- **높이 지도:** 256 → **512 해상도**, 메시 격자 2m → **1m 근경 / 원경 단순화**(필요 시 청크·LOD). 법선은 부드럽게(높이 지도 중앙 차분), 지형 셰이더 재질.
- **지형 셰이더:** 텍스처 세트 3~4종(풀, 흙/자갈, 바위, 모래) × (색·노멀·ORM) 1K. 섞기 = 경사(바위) · 높이(모래) · 저주파 노이즈(풀/흙 얼룩) + 높이 기반 경계. 바위는 삼면 투영. 거리에 따라 타일 반복이 보이지 않게 두 배율로 섞는다.
- **바위 모델:** CC0 바위 3~5종을 크기·회전 다르게 흩뿌려 지형 실루엣을 깨뜨린다(절벽 가장자리·둑·협곡 우선). 충돌은 단순 모양.
- **풀:** 카메라 반경 약 40m에 풀 덩어리(삼각형 몇 개짜리 카드) MultiMesh, 거리 페이드. 경사 45° 넘는 곳·물·길에는 없음.
- **고대 구조물(둑·탑·수문·기계):** 각진 형태 유지 + 실사 돌·금속 텍스처, 모서리 경사(bevel), 오래된 얼룩. 청록 코어 발광.
- **원경:** 섬 밖 1~3km에 산 능선 링(단순 메시) + 구름바다 느낌의 낮은 안개 — 플레이 영역보다 훨씬 넓어 보이게.

## 7. 빛과 대기

- 해 1개(그림자) + HDRI 하늘 환경광·반사. SSAO(틈새 그림자, 물체가 땅에 붙어 보이게) + SSIL(반사광) + 글로우(생명력 빛·코어·해).
- 볼류메트릭 안개는 **약하게**(공기감·빛줄기), 거리 안개로 공기 원근(하늘색). 높이 안개로 골짜기·저수호 위 옅은 안개.
- 하루 주기는 M5 이후(성능 실측 후).

## 8. 성능 예산 (S11 Ultra, Forward+, 60 FPS 목표 / 45 하한)

| 항목 | 예산 |
|---|---|
| 화면당 삼각형 | 약 50만 이하 (풀 포함) |
| 풀 인스턴스 | 카메라 주변 약 2~4만 덩어리 (실측 조정) |
| 그림자 드리우는 빛 | 1개, 그림자 거리 약 80m |
| 지형 텍스처 | 1K × 3~4세트 (색·노멀·ORM) |
| 후처리 | SSAO·SSIL·글로우·약한 볼류메트릭 안개, TAA 또는 FXAA 실측 비교 |
| 3D 해상도 스케일 | 0.75부터 |

효과를 하나 추가할 때마다 태블릿에서 장면 4곳 FPS를 다시 잰다 (`docs/perf/`).

## 9. 디자인 언어 (유지)

- 고대 장치: 각진 금속·돌 + 청록 발광 코어 + 예고 신호용 눈. 탑과 기계는 같은 문명의 언어.
- 사람·마을: 둥글고 따뜻한 나무·천.
- 주인공: 마을 사람과 같은 계열의 옷 + 포인트 색 1개.

## 10. 그래픽 개편 작업 순서 (계획서로 옮길 단위)

1. **하늘·대기:** HDRI 하늘(흐림↔맑음 섞기), 공기 원근 안개, 원경 산 링 — *광활함 효과 최대, 비용 최소*
2. **지형 셰이더:** 512 높이 지도, 부드러운 법선, 텍스처 섞기 + 회색↔컬러
3. **풀:** MultiMesh + 바람 + 회복 전/후 변화
4. **바위·구조물 재질:** CC0 바위 배치, 둑·탑·수문·집 실사 재질
5. **물:** 하늘 반사·반짝임 (Forward+ 반사 프로브/화면 공간 반사 실측)
6. 각 단계 후 태블릿 FPS 측정

## 11. 열린 질문

1. 섬 크기 확장 여부 — 1단계(하늘·원경) 후 판단
2. 캐릭터 CC0 팩 선택 (사실풍 재질과 어울리는 것)
3. GI(SDFGI/VoxelGI) 도입 여부 — 개편 후 FPS 여유 보고 판단
4. 저장소 용량 — 텍스처·HDRI가 늘어나므로 태블릿 git 용량 확인 (1K 텍스처·2K HDRI 기준 약 50~100MB 예상)
