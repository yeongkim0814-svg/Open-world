# 색칠 지도 그리기 안내서 (첫 섬 1km)

섬은 **PNG 4장**으로 정해진다. Notein에서 초안 그림 위에 덧칠해 고치고, 같은 이름으로 넣은 뒤 굽기를 돌리면 섬이 바뀐다.

| 파일 (`maps/first_island/`) | 정하는 것 |
|---|---|
| `height.png` | 높이 (색 띠 + 절벽 선) |
| `zones.png` | 식생 구역 7종 |
| `paths.png` | 흙길 · 고대 포장길 · 수로 |
| `markers.png` | 탑 · 저수호 · 수문 · 마을 · 폐허 · 전망대 · 다리 · 시작 위치 (점) |

**공통 규칙**
- 그림 한 장 = 1024m × 1024m. 위 = 북쪽. 초안은 1024×1024 픽셀(1픽셀 = 1m). 내보낸 크기가 달라도 **정사각형**이면 된다.
- **흰 종이 = 비어 있음.** 높이 지도에서 비어 있는 곳은 가까운 칠한 색으로 채워지고, 구역 지도에서는 초원이 된다.
- **아래 색만 쓴다.** 비슷한 색은 가장 가까운 범례색으로 읽히지만, 너무 다른 색은 무시된다. 펜 경계가 흐려도 괜찮다.
- 형광펜·반투명 펜은 쓰지 않는다(불투명 펜).

## 1. 높이 (`height.png`) — 지도책처럼 색 띠로

| 색 | 이름 | 높이 |
|---|---|---|
| `#1F3A5F` | 깊은 바다 | −12m |
| `#4F81BD` | 얕은 바다 | −3m |
| `#F2E6B8` | 해변 | 1m |
| `#9BBB59` | 평지 | 4m |
| `#C4D79B` | 언덕 | 12m |
| `#E3B46A` | 고원 | 24m |
| `#B07A4A` | 산 | 45m |
| `#7F6A93` | 고산 | 75m |
| `#E0218A` | **절벽 선** | 선 양쪽이 섞이지 않아 가파른 벽이 됨 (오를 수 있는 등반 벽) |

- 띠 사이는 게임이 약 12m에 걸쳐 부드럽게 잇는다 → 완만한 비탈.
- **절벽을 만들려면 두 띠 경계에 절벽 선을 긋는다.** 선이 조금 끊겨도 괜찮다.
- 저수호(둑·호수 바닥)와 탑 섬은 표식 위치에 정해진 모양이 자동으로 찍힌다 — 높이 지도에 그리지 않아도 된다.
- 가장자리 32m는 항상 깊은 바다.

## 5. Notein 작업 순서

1. 초안 PNG(`maps/first_island/*.png`)를 태블릿으로 가져온다 (Termux: `cd ~/storage/shared/Open-world && git pull` → 파일 관리자에서 `maps/first_island/` 폴더).
2. Notein 새 노트 → 페이지 배경(또는 이미지 삽입)으로 초안 한 장을 넣는다 → **같은 범례색 펜**으로 덧칠해 고친다. 한 페이지 = 지도 한 장.
3. 페이지를 **PNG로 내보내기** → 같은 이름(예: `height.png`)으로 `maps/first_island/`에 덮어쓴다. 고치지 않은 장은 그대로 둔다.
4. Termux: `git add maps/first_island/*.png && git commit -m "지도 수정" && git push`
5. 클라우드 세션에 "지도 구워줘"라고 요청 → 굽기 결과(`baked/preview.png`, 위에서 본 지도)를 확인 → 태블릿에서 `git pull` 후 `scenes/island_1km.tscn` 실행(F6).

**팁**
- 큰 지형(산·고원)부터 크게 칠하고, 절벽 선과 길은 마지막에.
- 처음에는 한 장씩 고쳐 굽기 결과를 보면 규칙을 빨리 익힌다.
- 펜 색은 Notein 색상 선택기에 위 HEX 코드를 직접 입력해 즐겨찾기로 저장해 두면 편하다.
