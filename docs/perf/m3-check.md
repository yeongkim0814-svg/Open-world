# M3 수호 기계 · 무기 확인 (태블릿)

업데이트: Termux에서 `cd ~/storage/shared/Open-world && git pull` → Godot에서 실행.

## 새 조작
| 입력 | 동작 |
|---|---|
| **무기 버튼** (오른쪽 위 작은 원, 무기 이름 표시) | 탭 = 다음 무기: 한손검 → 대검 → 활 |
| **공격 + 대검** | 느리지만 세다. 장갑 무시. **강공격(길게)** 은 적의 공격을 끊음 (0.8초 경직) |
| **공격 + 활** | 누르고 있기 = 당기기 (화면 확대 + 중앙 십자선, 걷기만) / 떼기 = 발사. 0.6초 당기면 최대 위력, 짧게 탭하면 약한 화살 |
| **수리대** (시작 지점 오른쪽 6m, 갈색 상자) | 앞에 서면 「수리: 무기 (부품 1)」 → 장착 무기 완전 수리 |

- HUD: `무기 이름 내구도/최대 (파손)`. 적을 맞힐 때만 닳음. 0이 되면 파손 → 피해 1/4.

## 수호 기계 (시작 지점에서 약 50m 앞)
- **칼날형** (왼쪽 앞, 상자 몸체): 15m 안에 들어가면 쫓아와 벤다. 🟡 베기 2번 → 🔴 1번. 장갑 때문에 **한손검·화살은 피해 40%**, 대검은 100%. 등 위 파란 구 = **코어(약점)** → 화살로 맞히면 2배.
- **포격형** (오른쪽 앞, 원기둥): 22m 안에서 경계, 8~20m 거리를 유지하며 탄을 쏜다. 🟡 탄(작음) = 패링하면 **되받아쳐** 포격형에 30 피해 / 🔴 탄(크고 빠름) = 회피. 포신 위 파란 구 = 코어.
- 집에서 25m 넘게 끌려가면 경계를 풀고 돌아가 체력을 회복한다.
- 처치하면 부품 1개를 떨어뜨리고 30초 뒤 부활.
