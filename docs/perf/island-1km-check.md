# 1km 섬 확인 (태블릿) — 첫 섬 교체 A

## 실행
1. `cd ~/storage/shared/Open-world && git pull` → Godot 에디터 껐다 켜기 (새 지도 파일 가져오기에 시간이 걸릴 수 있음).
2. `scenes/island_1km.tscn` 열기 → **현재 씬 실행(F6)**. ▶(메인 씬 = 옛 첫 섬)이 아님.
3. 왼쪽 위 패널: FPS·그리기·삼각형 / 구역·대기·생성 ms·회복 / 위치. 슬라이더 = 회복값.
4. 지금은 지형·바다·저수호 수면·**표식 위치 색 기둥**만 있음 (식생 = B, 구조물 = C).

## 컨테이너 측정 (참고, llvmpipe — 태블릿 FPS와 무관)
| 시점 | 그리기 | 삼각형 |
|---|---|---|
| 시작(마을 남쪽) | 181 | 25.2만 |
| 저수호 위 | 93 | 23.2만 |
| 북쪽 바위벽 | 51 | 21.7만 |
| 서쪽 협곡 | 52 | 22.0만 |
| 하늘에서 전경 | 202 | 13.8만 |

- 등반 스윕 199/200 (깜빡임 0).
