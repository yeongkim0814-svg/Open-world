# M1 태블릿 실측 기록 (Galaxy Tab S11 Ultra · Godot 4.7.2 Android 에디터)

## 0. 준비 (처음 한 번)

Termux에서:
```sh
pkg install git
termux-setup-storage                       # 저장소 접근 허용
cd ~/storage/shared                         # 공유 저장소 (Godot 에디터가 열 수 있는 위치)
git clone -b ccr-7055dd61-i6feki https://github.com/yeongkim0814-svg/Open-world.git
```
이후 업데이트는 `cd ~/storage/shared/Open-world && git pull`.

> push(기록 올리기)에는 GitHub 인증이 필요하다: GitHub → Settings → Developer settings → Personal access token 발급 후, push 시 비밀번호 자리에 토큰 입력.

Godot Android 에디터 → **가져오기(Import)** → `Open-world/project.godot` 선택 → 실행(▶).
- **측정 전 필수:** 게임이 에디터 옆(분할 화면)이나 에디터 안에 작게 뜨면 가로 고정·성능 측정이 틀어진다. 에디터 설정(Editor Settings)의 실행 창 배치(Run → Window Placement) 항목을 **전체 화면**으로 바꾸고, 게임이 화면 전체에 가로로 뜨는지 확인한 뒤 측정한다.
- 왼쪽 화면 아무 곳 누르고 끌기 = 이동 (끝까지 밀면 전력질주)
- 오른쪽 화면 끌기 = 카메라
- 오른쪽 위 밝은 원 = 점프 (공중에서 다시 누르면 활공 / 벽 쪽으로 밀면 등반)
- 흐린 원 2개(공격·방어)는 M2에서 연결됨
- 좌상단에 FPS·프레임 시간·상태·스태미나 표시

## 1. 섬 지도 (시작 지점 = 남쪽)

| 지점 | 위치 (시작에서 보아) | 확인할 것 |
|---|---|---|
| 5m 절벽 | 오른쪽 앞 | 쉽게 오르는가 |
| 15m 절벽 | 왼쪽 앞 | 오르면서 스태미나가 줄고, 끝에서 올라서는가 |
| 40m 절벽 (3단) | 정면 멀리 | 한 번에는 못 오름 → 단마다 쉬며 올라가는가 |
| 활공 언덕 + 경사로 | 오른쪽 옆 (멀리) | 경사로로 올라가 뛰어내려 활공 |
| 탑 기둥 (60m) | 오른쪽 멀리 | 멀리서 잘 보이는가 (랜드마크) |
| 바다 | 섬 밖 | 떨어지면 마지막 안전 지점에서 재시작 |

## 3. 조작감 체크리스트

- [ ] 스틱을 누른 채 다른 손가락으로 카메라를 돌려도 스틱이 풀리거나 튀지 않는다
- [ ] 40m 절벽을 쉬지 않고 오르면 스태미나가 바닥나 떨어진다
- [ ] 섬 밖으로 떨어지면 재시작된다
- [ ] 기기를 세로로 돌려도 가로 화면이 유지되고, 버튼이 화면 안에 있다

## 4. 판정

- 평균 FPS ≥ 55 → 통과, M2 진행
- 30 ~ 55 → 해상도 스케일·그림자 거리 조정 후 재측정
- 30 미만 → M2 전에 렌더링 설정 재검토
