# Compatibility 전환 호환성 목록 (2026-10-11, 스타일 개편 1부 Task 1)

측정: `tools/shots.sh compat_before both first_island` (xvfb + Mesa llvmpipe OpenGL 4.5). 테스트 184개 통과, 첫 섬 헤드리스 SCRIPT ERROR 0.

| 기능 | Compatibility 동작 | 2부(첫 섬 통합)에서 할 일 |
|---|---|---|
| SSIL · 볼류메트릭 안개 | 무시됨 (경고만) | 환경에서 제거, 높이 안개로 대체 |
| SSAO | 무시됨 (경고 없음) | 제거, 정점색 AO |
| 실사 텍스처 지형·구조물 | 전체가 하얗게 과노출(텍스처 색이 거의 사라짐) | 스타일 셰이더로 교체 (실사 셰이더는 폐기 예정이라 수정 안 함) |
| 하늘 셰이더 | 천정이 거의 검게, 구름판 흐릿 | `style_sky`로 교체 |
| 물 `hint_depth_texture` | 깊이 기반 알파·색이 동작하지 않아 호수가 불투명한 흰 판 | `style_water`(정점색 깊이)로 교체 |
| 풀 카드 | 그대로 보임(뾰족한 털 인상 그대로) | 덩어리형 풀로 교체 |
| 그림자 | 동작 | 유지 |
| 글로우 | 동작 | 약하게 유지 |

결론: 기존 실사 그래픽은 Compatibility에서 크게 깨진다 → 1부 테스트 씬 승인 후 2부에서 일괄 교체. 게임플레이는 영향 없음.
