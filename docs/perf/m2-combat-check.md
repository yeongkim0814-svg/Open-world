# M2 전투 확인 (태블릿)

업데이트: Termux에서 `cd ~/storage/shared/Open-world && git pull` → Godot에서 실행.

## 조작
| 입력 | 동작 |
|---|---|
| **공격** (오른쪽 아래) | 짧게 탭 = 공격 (3단 콤보) / 0.4초 이상 누르다 떼기 = 강공격. 적이 없어도 휘두름. 가까운 적이 있으면 자동으로 그쪽을 향함 |
| **방어** (공격 왼쪽) | 누르는 **순간** = 패링 판정 / 누르고 있으면 = 막기 (스태미나 15 소모) |
| **점프/회피** (공격 위) | 평소엔 방향 점프. 적이 공격 중이면 버튼이 **노란 「회피」** 로 바뀜 → 스틱 방향 + 버튼 = 앞 구르기 / 뒤로 도약 / 옆 도약 (무적 0.3초, 스태미나 15) |
| **줍기 팝업** | 주황색 부품 앞에 서면 「줍기: 기계 부품」 버튼이 뜸 → 탭 |

## 허수아비 (시작 지점에서 정면 20m, 2기)
- 2.5m 안에 들어가면 공격을 반복. 머리가 빛나면 공격 예고:
  - 🟡 노랑 = 패링 가능 → 빛나다가 몸을 숙이는 순간에 맞춰 **방어 버튼**
  - 🔴 빨강 = 패링 불가 → 막으면 가드 브레이크(1초 경직 + 피해) → **회피**
- 패링 성공 → 그 허수아비만 1.5초 느려짐 → 공격 연타
- 체력 100, 쓰러지면 3초 뒤 부활. 내 체력이 0이 되면 마지막 안전 지점에서 재시작.
- 좌상단 HUD: `HP / 부품 / ⚔전투 / 마지막 판정 결과(패링!·막기·가드 브레이크·피격·회피)`

- [ ] 패링 성공했을 때 짜릿한가? (예 / 보통 / 아니오) — 이유: ___
- [ ] 패링 판정 체감: 넓음 / 적당 / 좁음
- [ ] 회피(앞·뒤·옆)가 의도한 방향으로 나가는가
- [ ] 회피 중 화면이 흔들리지 않는가
- [ ] 회피 판정(무적) 체감: 넉넉함 / 적당 / 빡빡함
- [ ] 전투 진입 시 카메라 자동 정렬이 불편하지 않은가
- [ ] 오른손으로 카메라를 돌릴 때 카메라가 손가락과 싸우지 않는가
- [ ] 적이 없을 때 공격 휘두르기가 손에 붙는가 (탭이 늦게 나가는 느낌이 있는가)
- [ ] 강공격(길게 누르기)이 의도대로 구분되는가
- [ ] 전투 중에도 줍기 팝업이 뜨고 눌리는가
- [ ] 버튼 위치·크기 불편한 점: ___

## 판정
- 패링 성공률 30% 미만 → 판정 창을 넓혀 재확인
- 성공해도 재미없다 → 연타 보상(C5) 재설계 논의
- 그 외 → M3 (수호 기계 2종, 대검·활, 내구도)
