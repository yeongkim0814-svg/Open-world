# 그래픽 개편 1차 확인 (태블릿, Forward+)

업데이트: `cd ~/storage/shared/Open-world && git pull` → Godot 에디터 **완전히 껐다가 다시 열기** (텍스처 압축 설정이 바뀌어 처음 열 때 가져오기(import)가 오래 걸릴 수 있음) → 실행.
- 저장소가 약 30~40MB 늘었음 (지형 텍스처·바위 모델, 모두 CC0 — `assets/LICENSES.md`).
- HUD 첫 줄 `[forward_plus]` 확인.

## 바뀐 것 (눈으로 확인)
- 하늘: 흐린 먹구름 하늘 → 탑 정지 후 파란 하늘·흰 뭉게구름, 탑 위 먹구름이 걷힘
- 원경: 섬 밖 1~3km 산 능선 3겹, 멀수록 하늘색
- 지형: 실사 텍스처(풀·흙·바위·모래), 부드러운 굴곡, 절벽은 바위
- 풀: 카메라 주변 40m 풀, 바람에 흔들림. 회복 전 짧고 누런 풀 → 회복 후 키 큰 초록 풀
- 바위: 경사 가장자리에 실사 바위 약 120개
- 물: 깊이에 따른 색, 하늘 반사, 얕은 곳 청록
- 구조물: 탑·둑길·바위벽·집·수문이 돌·금속 재질
- 탑 소용돌이: 가는 잿빛 줄기
