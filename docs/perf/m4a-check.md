# M4a '첫 섬' 세계 확인 (태블릿)

업데이트: Termux에서 `cd ~/storage/shared/Open-world && git pull` → Godot에서 **가져오기 다시 하지 말고** 그대로 실행 (게임이 이제 '첫 섬'에서 시작).
> 처음 실행 시 지형을 만드느라 1~2초 멈출 수 있음 — 그 시간도 기록해 주세요.

## 섬 안내 (일부러 지도 마커 없음)
- 시작: 남쪽 마을 자리(임시 집 6채, 우물). 북쪽으로 **거대한 둑**과 그 위 탑, 탑으로 빨려 드는 **잿빛 소용돌이**.
- **수문 3곳** — 지형만 보고 찾아 보세요:
  - 북쪽 산 아래 **2단 바위벽**(15m + 15m) 위
  - 서쪽 **협곡 건너 고원** (능선 위 회색 바위에서 활공)
  - 동남쪽 **폐허 거점** (칼날형 2 + 포격형 1)
- 수문을 열 때마다 저수호 수위가 **3.9m씩** 내려감 (14.6 → 10.7 → 6.8 → 2.9). 둑길 옆 돌기둥이 차례로 드러나고, 3개면 둑길이 드러남.
- 탑: **계단식 4단**, 단마다 서서 스태미나를 채운 뒤 다음 단. 꼭대기 북쪽 끝 코어 앞에서 「정지」.
- 지형 경사: **60°까지 걸어서**, 그보다 가파르면 등반.
- **활공 = 공중에서 점프 버튼을 누르고 있는 동안** (떼면 접힘). 땅에서 점프한 뒤 계속 누르고 있으면 내려오기 시작할 때 펼쳐짐.
- HUD 맨 아래: `수문 n/3 · 탑 작동 중/멈춤`.
