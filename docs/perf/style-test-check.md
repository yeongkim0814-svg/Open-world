## 실행 방법
1. `cd ~/storage/shared/Open-world && git pull` → Godot 에디터 **껐다가 다시 열기** (렌더러가 Compatibility로 바뀜 — 재시작 필요).
2. 파일시스템에서 `scenes/style_test.tscn` 열기 → **현재 씬 실행**(▶ 옆 "씬 실행" 버튼, F6). 메인 씬(첫 섬)은 아직 옛 실사 그래픽이라 Compatibility에서 하얗게 깨져 보이는 게 정상 (2부에서 교체, `compat-audit.md`).
3. 왼쪽 위 패널: FPS·그리기·삼각형·회복값 표시, **회복 슬라이더**(0~1), 지형 평면 음영 토글, 안개 토글.

## 체크리스트 (예/아니오 + 한 줄)
- [ ] 풀이 불쾌하지 않은가 (털·가시 느낌이 없어졌는가)
- [ ] 절벽·바위에 반복 무늬가 없는가
- [ ] 폐허가 "도형에 텍스처"가 아니라 구조물로 읽히는가
- [ ] 회복 0 / 0.5 / 1 이 한눈에 구분되는가, 회복 1의 색감이 마음에 드는가
- [ ] 하늘·원경 산·바다가 안개로 자연스럽게 이어지는가
- [ ] 지형 평면 음영 켬/끔 중 어느 쪽이 좋은가
- [ ] 전체적으로 이 방향으로 첫 섬을 바꿔도 되는가 (아니면 무엇을 바꿀지)
