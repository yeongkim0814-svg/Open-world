# 첫 섬 교체 A — 색칠 지도 → 1km 지형 설계서

> 상태: 승인된 설계 (2026-10-12) · 상위: `docs/superpowers/specs/2026-10-11-stylized-graphics-design.md`(스타일), `2026-10-10-m4-first-island-design.md`(퀘스트·수치)
> 첫 섬 교체는 4개 하위 작업: **A 색칠 지도 → 1km 지형(이 문서)** → B 식생 7구역·약 25종 / C 구조물(병렬) → D 통합·정리(옛 실사 그래픽 삭제, 회복 연결, 웹 확인).

## 1. 목표

사용자가 태블릿 필기 앱(Notein)으로 그린 **색칠 지도 4장**을 게임이 읽어, 걸어 다닐 수 있는 **1024m × 1024m 섬**을 만든다. 그림을 고치고 굽기 도구를 다시 돌리면 섬이 바뀐다.

**성공 기준**
- 초안 지도로 만든 1km 섬을 걸어서·등반해서 돌아다닐 수 있다 (등반 스윕 성공률 ≥ 95%, 깜빡임 0).
- 사용자가 지도 한 장(예: 높이)을 고쳐 PNG로 넣고 굽기 → 고친 내용이 섬에 반영된다.
- 태블릿 60 FPS 목표 / 45 하한, 장면 예산 그리기 호출 < 150 · 삼각형 < 30만 (설계서 01 10.3).
- 기존 첫 섬(`first_island.tscn`)과 게임플레이는 D 전까지 그대로 동작 (테스트 220개 유지).

## 2. 결정 로그

| # | 질문 | 결정 |
|---|---|---|
| P1 | 그림 반영 방식 | **색칠 지도 → 게임이 읽기** (정해진 색 규칙의 PNG) |
| P2 | 맵 크기 | **1024m × 1024m** (1px = 1m 기준) |
| P3 | 높이 그리기 | **대략 높이 + 대표 색 구역** — 색 띠(지도책식)로 칠하고 게임이 부드럽게 잇는다. 절벽은 선 색으로 |
| P4 | 식생 구역 | 7구역: 초원 · 활엽수 숲 · 침엽수 숲 · 물가·습지 · 고지·바위산 · 해안 · 황무지(회복하면 초원으로) — 종 구현은 B |
| P5 | 볼거리 | 고대 수로·다리·길, 폐허·전망대 (그 외는 나중에 추가 가능) — 구조물 구현은 C, 위치 표식은 A |
| P6 | 시작점 | **Claude 초안 → 사용자가 고쳐 그림** |
| P7 | 그림 앱 | Notein (필기 앱) — 레이어 대신 **한 장 = 한 정보**, 불투명 펜, 크기 무관, 흐린 경계 허용 |
| P8 | 탐험 거리 | 퀘스트 핵심(수문 3·탑·마을) 사이를 수로·길·폐허·전망대로 채움. 원칙: 어디서든 갈 곳이 하나 이상 보임 (기둥 1) |

## 3. 색칠 지도 형식 (`maps/first_island/`)

모든 장: PNG, 정사각형이면 크기 무관(읽을 때 1024로 맞춤), **흰색(#FFFFFF)과 투명 = 비어 있음**. 각 픽셀은 범례에서 **가장 가까운 색**으로 판정하고, 거리가 문턱(RGB 거리 60)보다 크면 비어 있음으로 본다(펜 경계 흐림 무시).

### 3.1 `height.png` — 높이 색 띠

| 색 | 이름 | 목표 높이 (m) |
|---|---|---|
| `#1F3A5F` | 깊은 바다 | −12 |
| `#4F81BD` | 얕은 바다 | −3 |
| `#F2E6B8` | 해변 | 1 |
| `#9BBB59` | 평지 | 4 |
| `#C4D79B` | 언덕 | 12 |
| `#E3B46A` | 고원 | 24 |
| `#B07A4A` | 산 | 45 |
| `#7F6A93` | 고산 | 75 |
| `#E0218A` | 절벽 선 (높이 없음) | — 선을 사이에 둔 두 띠는 섞지 않음 → 가파른 벽 |

- 비어 있는 칸 = 가장 가까운 칠한 칸의 값으로 채움(빈틈 허용). 지도 가장자리 32m는 강제로 깊은 바다.
- 높이 = 띠 목표값 → **거리 기반 평활화**(반경 약 12m, 절벽 선은 넘지 않음 → 절벽 양쪽은 1~2m 안에서 높이가 바뀌어 60° 이상 벽이 됨) → 저주파 굴곡(진폭 1.5m, 주기 약 40m; 바다·절벽 근처는 줄임).
- **정밀 지형은 표식 도장으로:** 저수호(둑 포함)·탑 섬처럼 퀘스트 수치가 정해진 곳은 표식 위치에 코드가 정확한 모양을 찍는다(3.4).

### 3.2 `zones.png` — 식생 구역

| 색 | 구역 |
|---|---|
| `#A9D18E` | 초원 (비어 있으면 기본값) |
| `#548235` | 활엽수 숲 |
| `#375623` | 침엽수 숲 |
| `#5FB3B3` | 물가·습지 |
| `#A6A6A6` | 고지·바위산 |
| `#FFE699` | 해안 |
| `#C55A11` | 황무지 |

A에서는 구역별 **땅 색**만 반영(지형 셰이더), 식물 배치는 B.

### 3.3 `paths.png` — 길·물길 (칠한 폭 = 실제 폭)

| 색 | 종류 | 효과 (A) |
|---|---|---|
| `#8B5A2B` | 흙길 | 땅 색 = 흙, 지형을 길 방향으로 약간 평평하게(최대 0.5m) |
| `#404040` | 고대 포장길 | 땅 색 = 돌, 평평하게 (C에서 포장 부품 배치) |
| `#2E75B6` | 수로 | 바닥을 1.5m 파냄 (C에서 수로 부품·물) |

### 3.4 `markers.png` — 표식 (색 점, 이어진 덩어리의 중심 = 위치)

| 색 | 표식 | A에서 하는 일 |
|---|---|---|
| `#000000` | 시작 위치 | 플레이어 시작 |
| `#FF0000` | 탑 | 도장: 탑 섬(바위 기둥 윗면 18m) |
| `#00B0F0` | 저수호 중심 | 도장: 반경 48m 분지(바닥 −6m) + 높이 16m 둑 고리 (M4 수치) |
| `#FF8C00` | 수문 (최대 3) | 위치만 기록 (C) |
| `#FFFF00` | 마을 중심 | 반경 40m를 평지로 다듬음 |
| `#7030A0` | 폐허 | 위치만 기록 (C) |
| `#FF66CC` | 전망대 | 위치만 기록 (C) |
| `#00FF00` | 다리 | 위치만 기록 (C) |

방향은 기본값(마을·저수호를 바라봄). 나중에 표식 데이터(JSON)에서 고칠 수 있다.

## 4. 굽기 (`tools/bake_map.gd`)

`godot --headless -s tools/bake_map.gd -- first_island` → `maps/first_island/baked/`:
- `height.png` — 1024×1024 RGB8 16비트(R 상위·G 하위, 기존 `HeightField` 관례), 범위 −16 ~ 90m
- `zones.png` — R8 구역 번호, `paths.png` — R8 길 종류 번호
- `markers.json` — `[{kind, x, z, yaw}]`
- `preview.png` — 위에서 본 색 지도(높이 음영 + 구역 색 + 길 + 표식) — 사용자 확인용

게임은 구운 파일만 읽는다(시작 속도). 굽기는 결정적(같은 입력 = 같은 출력). 순수 계산은 `scripts/core/map/`(노드 비의존, TDD): `MapLegend`(색 판정), `HeightBands`(띠 → 높이·평활화·절벽), `MarkerReader`(덩어리 중심), `MapStamps`(저수호·탑 섬·마을 평지).

## 5. 1km 지형 (`scripts/nodes/chunked_terrain.gd`)

- 64m 구역 16×16. 거리별 격자: < 160m → 1m, < 480m → 4m, 그 밖 → 16m. 구역 경계 틈은 **치마(아래로 내린 테두리)**로 가림.
- 메시는 실행 중 생성, **프레임당 생성 시간 ≤ 4ms** 예산(대기열). 웹은 스레드 없음 → 메인 스레드 분할 생성.
- 충돌: 플레이어 주변 3×3 구역만 1m `HeightMapShape3D`, 이동하면 교체.
- 재질: `style_terrain` + `zone_map`·`path_map` 텍스처(가장 가까운 칸 샘플)로 구역·길 땅 색. 평면 음영은 1m 구역만.
- 물: 바다(기존 스타일 물, `use_here`) + 저수호 수면(도장 위치, 수위 기존 규칙).

## 6. 초안 지도 (`tools/draft_first_island.gd`)

현재 배치를 1km에 펼친 초안 PNG 4장을 만든다: 거리 약 3배, 구조물 크기 그대로.
- 북: 고산·산(샘) + 침엽수 숲, 수문 1은 바위벽(절벽 선) 위
- 서: 협곡(절벽 선 두 줄) + 고지·황무지, 수문 2는 협곡 건너
- 중앙: 저수호 도장 + 둘레 습지, 탑 주변 황무지
- 동: 활엽수 숲, 동남 수문 3 거점
- 남: 평지 초원 + 마을, 가장자리 해안
- 수로: 북쪽 샘 → 수문들 → 저수호 → 마을 우물. 흙길: 마을 ↔ 각 목표. 폐허 3·전망대 2 표식.

## 7. 사용자 안내서 (`docs/guides/map-painting.md`)

범례 표(색 코드), Notein에서 페이지 하나에 지도 한 장 → **페이지를 PNG로 내보내기**(안 되면 PDF → 클라우드에서 변환), 초안 PNG를 배경으로 불러와 덧칠하는 법, 파일 위치, `git` 올리기, 굽기는 클라우드 세션(또는 PC)에서 실행한다는 점, 확인은 `preview.png` → 에디터 실행.

## 8. 시험 장면 (`scenes/island_1km.tscn`)

지형·바다·저수호 수면·플레이어·회복 지도(시험값)·디버그 패널(FPS·구역 수·삼각형·위치) + 표식 위치에 색 기둥(디버그). 기존 `first_island.tscn`은 D까지 메인 씬으로 유지.

## 9. 테스트

- 단위(TDD): 색 판정(가장 가까운 색·문턱·흰색/투명 = 비어 있음), 띠 → 높이, 평활화가 절벽 선을 넘지 않음(절벽 양쪽 경사 ≥ 60°), 빈칸 채우기, 가장자리 바다, 표식 중심, 도장 수치(저수호 둑 꼭대기 16m·바닥 −6m), 크기 맞춤, 굽기 결정성, LOD 선택 함수, 치마가 틈을 덮음(인접 LOD 경계 높이 차 ≤ 치마 깊이).
- 탐침: 1km 등반 스윕(≥ 95%), 수영(저수호), 걸어서 해안 → 산 경로.
- 시각: `preview.png` + 시점 스크린샷. 성능: 그리기 호출·삼각형·청크 생성 시간(헤드리스 측정), 태블릿 FPS(사용자).

## 10. 위험·열린 질문

1. Notein이 페이지를 PNG로 내보내는지 미확인 → 안 되면 PDF 변환 단계 추가.
2. 실행 중 청크 생성이 태블릿·웹에서 느리면 → 1m 반경 축소 또는 굽기 시 LOD 메시 저장.
3. 띠 평활화가 의도와 다른 경사를 만들 수 있음 → 미리보기로 확인, 반경 조정 가능(굽기 설정).
4. 퀘스트 거리 3배 → 탐험 시간 증가. 활공·수로 안내선으로 보완, 체감은 사용자 시험으로 판단.
