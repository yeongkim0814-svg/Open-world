# 첫 섬 교체 A2 — 2km 지역 · GPT 지도 보정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** 설계서 11장(개정 A2)대로 2048m 지역을 굽고 걷게 한다.
**Spec:** `docs/superpowers/specs/2026-10-12-painted-map-terrain-design.md` 11장 (1~10장은 그대로 유효)

## Global Constraints
- 1px = 1m, 지도 2048². 설정은 `maps/<map>/map.json` 한 곳. 굽기 결과에 `baked/meta.json` (`world`, `min_h`, `max_h`, `size`).
- 띠 높이·평활화·인코딩 범위·가장자리 = 설계서 11장 P10·P11 값.
- 기존 테스트 유지(값이 바뀐 띠 높이 테스트는 새 값으로), 결정적 굽기.

## Review Focus
1. 저수호 도장이 높은 산 위에서도 "둑 + 깊은 분지"가 되는가 (꼭대기 > 주변, 바닥 = 꼭대기 − 22) → Task 1 `test_lake_stamp_relative_on_high_ground`
2. 지도 가장자리 강제 바다 끄기 → 칠한 육지가 가장자리까지 유지 → Task 1 `test_edge_sea_off_keeps_land`
3. 먼 묶음(256m)과 64m 구역 경계 틈 → 측정 치마 적용 → Task 2 `test_block_and_chunk_seam_covered`
4. 맵 크기가 1024가 아닐 때(2048) 좌표·충돌·셰이더 map_rect 일치 → Task 2·3 테스트
5. 개천 파기가 마을 평탄화·저수호 도장과 겹칠 때 순서(도장 → 길 → 개천) → Task 1 `test_stream_dug_after_stamps`

### Task 1 (에이전트 P): 굽기 파이프라인 개정
Files: `scripts/core/map/{map_legend,height_bands,map_stamps,map_baker,marker_reader}.gd`, `tools/bake_map.gd`, 테스트.
- `MapLegend`: 띠 `h` 새 값, `PATHS`에 `{"color": #6FA8DC, "name": "stream"}`(구운 값 4), `MARKERS["hill_village"] = #FFC000`.
- `MapBaker.bake(layers, size, world, cfg := {})` — cfg: `smooth_radius`(기본 12), `edge_sea`(기본 true), `min_h`·`max_h`(기본 −16·90, encode용). `encode_height(h, size, min_h := -16.0, max_h := 90.0)`.
- `HeightBands.build(..., edge_sea := true)`.
- `MapStamps`: 저수호 상대 높이(P12), 반환 또는 기록으로 crest·tower top을 마커에 넣음(`markers[i]["crest"]`, 탑 `["top"]`). `hill_village`는 도장 없음.
- 개천: V자 2.5m 파기, 도장·흙길 평탄화 **뒤**.
- `tools/bake_map.gd`: `map.json` 읽기(없으면 기본값), `baked/meta.json` 쓰기.
- 테스트: 위 Review Focus 1·2·5 + `test_stream_profile`(중앙 −2.5, 가장자리 0), `test_meta_written`(도구 대신 `MapBaker.meta(cfg, size, world)` 함수 테스트), `test_hill_village_not_flattened`.

### Task 2 (에이전트 T): 지형 노드 2km + 먼 묶음
Files: `scripts/core/terrain/{terrain_lod,chunk_mesh}.gd`, `scripts/nodes/chunked_terrain.gd`, 테스트.
- `ChunkedTerrain.load_map()`이 `baked_dir/meta.json`에서 world·min_h·max_h를 읽음(없으면 1024·−16·90).
- 먼 묶음: 256m 블록(4×4 구역)의 모든 구역이 16m 간격을 원하면 블록 메시 하나(16m 간격, 측정 치마)로 그리고, 아니면 64m 구역들. 깊은 바다 생략 규칙은 블록에도 적용.
- `stats()`에 `blocks` 추가. 테스트: Review Focus 3·4 + `test_far_blocks_reduce_nodes`(2048 합성 지도, 카메라 한쪽 끝 → 노드 수 < 300).
- 성능 탐침: 2048 합성 지도에서 정상 상태 그리기 노드 수·삼각형·최악 생성 ms 보고.

### Task 3 (메인): GPT 지도 보정 + 장면 + 탐침
- `tools/fix_gpt_map.gd`: GPT 원본(`maps/first_island/source_gpt/`) → 보정 PNG 4장 + `map.json`. 보정 = P15.
